3. 潜在リスク Top 5

  • 高 優先度 ① 仮想マシンの Defender High 推奨未対応（12件）
    観察事実
    Defender High 推奨16件中12件が Microsoft.Compute/virtualMachines に集中。カテゴリはほぼ "Unknown" のため、内容の詳細把握が必要。
    影響
    未対応の構成不備が攻撃経路となりうる。High 推奨は通常、エンドポイント保護の欠如・脆弱な認証設定等を含む可能性がある。
    推奨対応
    Azure Portal の Microsoft Defender for Cloud で High の推奨事項を一覧化し、各推奨の詳細と対象リソースを特定する。是正順序はビジネス影響度と対応コストで優先付けする。
  • 高 優先度 ② 仮想マシン向け Advisor Security High（12件）
    観察事実
    Advisor High Impact かつ Security カテゴリの推奨12件が VM に存在。Advisor Security 全91件の中核を占める可能性がある。
    影響
    セキュリティ設定の乖離が広範にある場合、侵害時の影響範囲が拡大する恐れがある。
    推奨対応
    Azure Advisor のセキュリティカテゴリで High フィルタを適用し、VM 向け推奨の詳細を確認。Defender の推奨と重複する場合は統合管理で対応効率を上げる。
  • 高 優先度 ③ ディスクの可用性リスク — Advisor HighAvailability High（12件）
    観察事実
    Microsoft.Compute/disks に対する HighAvailability High 推奨が12件。ディスク12件が取得されており、大半に何らかの可用性改善推奨が存在する可能性がある。
    影響
    バックアップ未設定やゾーン冗長の欠如は、障害・誤削除時にデータ損失が発生するリスクを示す。
    推奨対応
    Azure Backup の有効化状況とゾーン冗長ディスク設定を確認し、RPO/RTO 要件に基づいてバックアップポリシーを設定または強化する。
  • 高 優先度 ④ 広スコープ Owner ロール割り当て（15件）
    観察事実
    Owner 15件のうち、Subscription・ManagementGroup スコープへのロール割り当てが全体の81%を占める環境において、Owner 権限の適切な範囲制限が確認されていない。
    影響
    過剰な Owner 権限は、アカウント侵害時に環境全体への影響が生じるリスクがある。不要な Owner 割り当ては内部不正リスクも高める。
    推奨対応
    Owner ロールの棚卸しを実施し、実業務上不要な割り当ては削除またはより制限されたロールへ変更する。特にManagementGroup・Subscriptionスコープの Owner を重点確認する。
  • 中 優先度 ⑤ VM の OperationalExcellence 改善推奨（Advisor High 11件）
    観察事実
    VM に対する Advisor OperationalExcellence High が11件。設定ドリフトや診断設定の不備等が含まれる可能性がある。
    影響
    運用品質の低下は障害検知遅延・対応遅延につながり、インシデント時のMTTRを悪化させる恐れがある。
    推奨対応
    Advisor OperationalExcellence カテゴリを確認し、診断ログ・アラート設定の整備を優先する。Security・HighAvailability 対応後に着手することを推奨する。
