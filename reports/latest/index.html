総評

本環境は 90 リソースを擁する中規模 Azure 環境であり、VM・ディスク・ネットワーク・ストレージを中心に構成されている。 最大のリスク集中領域は 仮想マシンのソフトウェア更新不足 であり、Defender High の 115 件中 101 件がこのカテゴリに該当する。 Advisor も High Impact 77 件のうち 40 件が VM の Security 推奨であり、同一資産への多重リスクが確認される。 ロール割り当ての 91% がサービスプリンシパル、サブスクリプション・管理グループスコープが支配的であるため、 最小権限設計の検証が優先課題となる。一方、NSG 危険ルールはゼロであり、ネットワーク境界の基本統制は確認できる。 VM 以外のリソースタイプや Unknown カテゴリ推奨の詳細については追加確認が必要。

主要懸念事項

  • 【高】VM ソフトウェア更新欠落（101 件）： Defender High の約 88% が VM のソフトウェア更新カテゴリに集中。更新未適用のまま運用継続するとエクスプロイトリスクが高まる。環境内 VM 11 台に対し 101 件の指摘は平均 9 件超／台を示唆し、組織的な更新プロセスの見直しが急務。
  • 【高】Defender 未健全推奨の高率（53%）： Defender 推奨 510 件中 271 件が Unhealthy 状態。全体の半数超が対処されておらず、セキュリティ態勢の継続的な改善サイクルが機能していない可能性がある。
  • 【中】Advisor Security High Impact（40 件・VM）： Advisor も VM を対象とした Security カテゴリで 40 件の High Impact 推奨を記録。Defender 指摘と重なるリソースが存在すると想定され、統合対応による効率化が必要。
  • 【中】サブスクリプション・管理グループスコープへの権限集中： ロール割り当て 42 件のうち 41 件（98%）がサブスクリプション以上のスコープ。広範な権限が多数のリソースへ一括適用されている状態は、インシデント発生時の影響範囲拡大につながる。最小権限設計の確認が必要。
  • 【中】Unknown カテゴリ Defender 推奨（76 件）： 分類が "Unknown" の推奨が 76 件存在する。内容の特定にはポータルや API で個別確認が必要であり、現状ではリスク内容を評価できない。

強み・確認できた統制

  • NSG 危険ルール ゼロ：取得した 12 件の NSG ルールに危険分類は確認されず、ネットワーク境界の基本フィルタリング統制は維持されている。
  • 高可用性推奨が把握済み：Advisor High HA 推奨 11 件（ディスク対象）が識別されており、対応の優先順位付けが可能な状態にある。
  • 全データ領域の取得成功：Resources・RBAC・NSG・Defender・Advisor の 5 領域すべてのデータが取得済みであり、横断的な分析基盤が整っている。
  • Owner ロールの把握：Owner 割り当て 13 件が識別済みであり、権限棚卸しの出発点として活用できる。

3. 潜在リスク Top 5

高 #1

VM ソフトウェア更新 — Defender High（101 件）

観察事実
Microsoft.Compute/virtualMachines を対象とした Defender High・SoftwareUpdate カテゴリの指摘が 101 件。Defender High 全体（115 件）の 88% に相当。
影響
ソフトウェア更新未適用の VM は既知の脆弱性に晒され続ける可能性があり、環境全体のセキュリティ態勢に直結する。
推奨対応
Azure Update Manager または WSUS で対象 VM の更新適用状況を確認し、未適用パッチを特定・適用する。対応完了後に Defender でステータスを再評価する。
高 #2

Defender Unhealthy 率 53%（271/510 件）

観察事実
Defender 推奨 510 件のうち 271 件（53%）が Unhealthy 状態。High 115・Medium 118・Low 38 で構成される。
影響
半数超が未対処のままでは、Defender による継続的改善サイクルが機能していない可能性があり、組織のセキュア スコア改善も停滞する。
推奨対応
Microsoft Defender for Cloud ポータルで Unhealthy 推奨を High → Medium の順にトリアージし、Quick Fix が利用可能なものから対処する。ガバナンスルール設定による担当者割り当ても有効。
高 #3

VM Security — Advisor High Impact（40 件）

観察事実
Advisor High Impact・Security カテゴリの VM 向け推奨が 40 件。Advisor Security 推奨全体（161 件）の 25% を占める。
影響
Defender の指摘と対象 VM が重複していると想定される場合、対処遅延は多面的なリスク露出となる。
推奨対応
Azure Advisor ポータルで対象 VM の Security 推奨詳細を確認し、Defender 推奨との統合対応計画を策定する。
中 #4

サブスクリプション・管理グループへの権限集中（41/42 件）

観察事実
ロール割り当て 42 件のうち Subscription スコープ 28 件・ManagementGroup スコープ 13 件・ResourceGroup スコープ 1 件。サービスプリンシパルが 38 件（90%）。
影響
広範スコープへの権限集中はインシデント発生時の横移動リスクを高める。最小権限原則からの逸脱は監査指摘の対象になりやすい。
推奨対応
Owner ロール 13 件について使用実績・業務要件を確認し、不要なサブスクリプション・管理グループ スコープの割り当てをリソースグループスコープへ絞り込む。
中 #5

ディスク高可用性 — Advisor High Impact（11 件）

観察事実
MICROSOFT.COMPUTE/DISKS を対象とした Advisor High Impact・HighAvailability 推奨が 11 件。
影響
可用性設計の不備は障害時のデータ損失・復旧時間の長期化につながる可能性がある。
推奨対応
Azure Advisor でディスクの HA 推奨詳細（冗長性設定・スナップショット有無）を確認し、SLA 要件に照らして是正計画を立案する。
