本環境は 90 リソースで構成され、Compute（VM・ディスク）と Network（NSG・NIC・VNet）が中心を占める中規模構成です。 セキュリティ態勢の観点では、Microsoft Defender が 514 件の推奨事項を検出しており、うち 119 件（23%）が High 重大度です。 SoftwareUpdate カテゴリが 165 件と最多であり、VM のパッチ適用状況が最も大きなリスク集中領域です。 Advisor も 232 件の推奨を提示しており、Security カテゴリが 161 件と群を抜いています。 一方、NSG の危険ルールは 0 件であり、ネットワーク境界設定は現状把握の範囲で良好です。 IAM では Owner 権限が 13 件確認されており、Subscription・ManagementGroup スコープの割り当てが大半を占めることから、権限範囲の適切性を個別確認することを推奨します。

主要懸念事項

【高】VM のソフトウェア更新未適用（Defender High: 105件） Microsoft.Compute/virtualMachines に対し、SoftwareUpdate カテゴリの Defender High 推奨が 105 件集中しています。 パッチ未適用の VM は既知の脆弱性を長期間公開する可能性があり、ランサムウェアや不正アクセスの足がかりになりえます。 対象 VM の特定と緊急パッチ適用計画の策定が急務です。
【高】VM 向け Advisor Security 推奨（High: 40件） VM に対して Advisor の Security カテゴリ High 推奨が 40 件あります。 Defender と重複しない追加の設定不備・構成リスクが含まれる可能性があり、組み合わせて評価することで対応優先度が上がります。 Defender との差分を確認し、独自の是正アクションが必要な項目を特定してください。
【高】ディスクの高可用性未設定（Advisor HighAvailability High: 11件） MICROSOFT.COMPUTE/DISKS への Advisor 高可用性推奨が 11 件あります。 ゾーン冗長や可用性セットへの配置が不十分な場合、ゾーン障害時にデータ損失・サービス停止が生じる恐れがあります。 本番ワークロードのディスク設定を優先的に見直してください。
【中】Subscription・MG スコープの広域ロール割り当て（合計 41件） 42 件のロール割り当てのうち 28 件がサブスクリプション、13 件がマネジメントグループスコープです。 広域スコープの割り当ては最小権限原則から逸脱するリスクがあり、特に ServicePrincipal（38件）は対象スコープ・目的の正当性確認が必要です。 ResourceGroup スコープへの絞り込みを検討してください。
【中】Defender 未分類（Unknown）カテゴリの推奨（High: 11件） カテゴリが Unknown の Defender High 推奨が VM に 11 件存在します。 分類不明の推奨は見落とされやすく、実際のリスク内容を Azure Portal または API で個別確認する必要があります。 無視せず、内容を精査して適切な是正処置を行ってください。
