本環境は 90 リソース（VM・ディスク・NIC・NSG・ストレージ等）を中心に構成される中規模 Azure 環境です。 最大の懸念は Defender が検出した 93 件の High 重大度推奨事項で、その大部分は VM のソフトウェア更新未適用に集中しています。 Advisor も High Impact 77 件（うちセキュリティ 40 件超）を指摘しており、セキュリティ態勢の改善余地が大きいと評価されます。 一方で、NSG の危険ルールが 0 件であること、RBAC 割り当て数が限定的であることは肯定的に評価できます。 公開境界については NSG データから直接的な過剰公開は確認されませんが、VM の更新状況を踏まえると暴露リスクを追加確認する必要があります。 特権境界に関しては Owner ロールが 13 件割り当てられており、範囲・主体の確認が推奨されます。

主要懸念事項

  • 【最高優先】VM ソフトウェア更新未適用（Defender High：79 件）
    仮想マシン (Microsoft.Compute/virtualMachines) に対する Defender の High 推奨事項が 79 件集中しており、これは Defender High 全体（93 件）の約 85%を占めます。パッチ未適用のまま放置すると、既知の脆弱性を利用したリモート攻撃やマルウェア感染のリスクが高まります。即時の更新対応計画が必要です。
  • 【高優先】VM セキュリティ設定の Advisor 指摘（Advisor High Security：40 件）
    VM に対する Advisor の High Impact Security 推奨事項が 40 件あり、セキュリティ構成上の改善が必要な箇所が多数存在することを示しています。ソフトウェア更新とあわせて優先対応することで、リスクの重複削減が期待できます。
  • 【高優先】ディスクの高可用性設定（Advisor High HighAvailability：11 件）
    ディスク (MICROSOFT.COMPUTE/DISKS) に対する高可用性の Advisor 推奨事項が 11 件あり、単一障害点や RTO/RPO への影響が懸念されます。可用性要件に基づきバックアップや冗長構成の見直しを検討する必要があります。
  • 【中優先】Defender 不健全推奨事項の総量（231 件）
    Unhealthy 状態の Defender 推奨事項が合計 231 件あり、High 以外の Medium（107 件）・Low（31 件）についても段階的な改善が必要です。放置すると Secure Score への継続的な影響と運用負債が累積します。
  • 【要確認】Owner ロール割り当て（13 件・主にサブスクリプションおよび管理グループスコープ）
    Owner ロールが 13 件割り当てられており、そのうち多くがサブスクリプションまたは管理グループスコープで付与されていると推測されます（詳細は追加確認が必要）。サービスプリンシパルへの広域 Owner 付与は特権昇格リスクに直結するため、最小権限原則に従ったレビューが推奨されます。

強み・確認できた統制

  • NSG の危険ルールがゼロ（0/12 件）
    12 件の NSG ルールを確認しましたが、危険と分類されるルールは 0 件でした。ネットワーク境界の基本統制が機能していることを示しており、適切な NSG 管理が行われていると評価されます。

  • ロール割り当てが Service Principal 主体（38/42 件）

3. 潜在リスク Top 5

優先度：高 ① VM ソフトウェア更新未適用（Defender High SoftwareUpdate）
観察事実
Defender High / SoftwareUpdate カテゴリで仮想マシン (Microsoft.Compute/virtualMachines) に対して 79 件の推奨事項が未対応。
影響
ソフトウェア更新が長期間適用されていない VM は既知の CVE を悪用した侵入・横断移動の起点となるリスクがあります。
推奨対応
Azure Update Manager または OS 付属の更新管理機能を使い、対象 VM を特定して速やかにパッチ適用計画を立案・実行してください。Defender の推奨事項詳細で対象リソース一覧を確認できます。
優先度：高 ② VM セキュリティ構成の Advisor 指摘（Advisor High Security）
観察事実
Advisor High Impact / Security カテゴリで VM に対して 40 件の推奨事項が未対応。
影響
セキュリティ構成の不備（暗号化、診断設定、エンドポイント保護など）は、リスク①と複合して攻撃対象領域を拡大させます。
推奨対応
Azure Advisor の [セキュリティ] タブで対象 VM 一覧を確認し、推奨事項の種類ごとに是正ロードマップを作成してください。
優先度：高 ③ Defender 不明カテゴリ High 推奨事項（Unknown）
観察事実
Defender High / Unknown カテゴリで VM に対して 11 件の推奨事項が存在。カテゴリが "Unknown" の項目はポリシー未設定や新機能起因の可能性があります。
影響
内容が未分類のまま放置すると見落とし要因となり、想定外の設定不備が残存するリスクがあります。
推奨対応
Defender for Cloud ポータルで Unknown カテゴリの詳細を確認し、内容に応じて SoftwareUpdate または構成変更として対処してください。
優先度：中 ④ ディスク高可用性の未対応（Advisor High HighAvailability）
観察事実
Advisor High Impact / HighAvailability カテゴリでディスク (MICROSOFT.COMPUTE/DISKS) に対して 11 件の推奨事項が未対応。
影響
ディスクの冗長設定が不十分な場合、ハードウェア障害時にデータ損失や長時間のサービス停止が発生するリスクがあります。
推奨対応
Azure Backup またはゾーン冗長ストレージ (ZRS) の導入、Managed Disk スナップショットのスケジュール設定を検討し、RTO/RPO 要件に照らして対象を絞り込んでください。
優先度：中 ⑤ Owner ロールの広域割り当て（RBAC ガバナンス）
観察事実
Owner ロール割り当て 13 件のうち、RBAC データではサブスクリプションスコープ 28 件・管理グループスコープ 13 件の割り当てが確認されており、広域スコープでの権限付与が存在します（Owner 割り当て 13 件がどのスコープに属するかは追加確認が必要）。
影響
広域 Owner 権限を持つプリンシパルが侵害・誤操作された場合、環境全体に影響が及ぶ可能性があります。
推奨対応
Owner ロールの割り当て対象と範囲を棚卸しし、必要最小限の権限（Contributor 等）への変更を検討してください。サービスプリンシパル（38 件）については用途確認も実施してください。
