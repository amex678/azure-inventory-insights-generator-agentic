総評： 本環境は仮想マシンを中心とした 90 リソースの中規模 Azure 環境です。Defender が検出した高重大度推奨事項が 93 件（不健全推奨事項 223 件中）、Advisor 高影響度推奨事項が 43 件あり、特に VM のソフトウェア更新とディスクの可用性に集中しています。セキュリティ態勢・運用安定性の両面で即時対応が求められます。一方、NSG の危険ルールはゼロであり、ネットワーク境界は一定水準を維持しています。特権ロール（Owner）の 13 件割り当てとサブスクリプション・管理グループスコープの広範な RBAC は、追加確認が必要な領域です。

主要懸念事項

① VM のソフトウェア更新未適用（Defender High: 79 件）
高重大度の Defender 推奨事項 93 件のうち 79 件が VM の SoftwareUpdate カテゴリ。リソース総数 90 に対して VM への未パッチが集中しており、既知脆弱性を悪用されるリスクが高い状態です。未更新の数が多いほど、侵害経路として優先されやすくなります。
② Defender 不健全推奨事項が全体の 54.8%（223/407 件）
Defender 推奨事項 407 件中 223 件が不健全（Unhealthy）状態。高・中合計で 192 件が未対応であり、セキュリティ態勢スコアへの影響と対応漏れリスクが高い。カテゴリ内訳で "Unknown" が 71 件あり、分類不明の推奨事項が精査されていない可能性があります。
③ ディスクおよび VM の可用性・運用上の高影響度推奨事項（Advisor High: 43 件）
Advisor 高影響度推奨事項 43 件のうち、ディスク（HighAvailability: 11 件）と VM の OperationalExcellence（11 件）が上位。可用性ゾーンや冗長性の未設定が示唆され、障害時の復旧遅延につながる恐れがあります。
④ Owner 割り当て 13 件とサブスクリプションスコープ RBAC の集中
ロール割り当て 43 件のうち 29 件がサブスクリプションスコープ、13 件が管理グループスコープ。Owner 13 件は最小権限原則から逸脱している可能性があり、特にサービスプリンシパル（38 件）が広いスコープを持つ場合、侵害時の影響範囲が拡大します。追加確認が必要です。
⑤ Advisor セキュリティカテゴリの高影響度推奨事項（Security: 11 件）
Advisor の Security カテゴリ合計 71 件中、High が 11 件。Defender とは異なる観点（診断設定・暗号化・アクセス制御など）からの推奨事項が含まれており、Defender との重複確認と組み合わせた優先付けが推奨されます。

強み・確認できた統制

✓ NSG 危険ルールがゼロ
検出された 12 件の NSG ルール中、危険と判定されたものはゼロ。ネットワーク境界アクセス制御が一定水準で維持されていることを示しています。
✓ 5 つのデータ領域すべてで棚卸し取得済み
リソース・RBAC・NSG・Defender・Advisor の全領域でデータ収集が完了しており、棚卸しの網羅性が確保されています。可視化の前提条件が整っています。
✓ RBAC 割り当ての大半がサービスプリンシパル
ロール割り当て 43 件中 38 件（88%）がサービスプリンシパル。人的アカウントへの直接権限付与が最小化されており、自動化された認証管理が基盤として機能しています。ただし各 SP の用途・権限範囲は別途確認が必要です。

3. 潜在リスク Top 5

優先度：高 VM のソフトウェア更新未適用（Defender High / SoftwareUpdate）
観察事実Defender 高重大度 93 件中 79 件が Microsoft.Compute/virtualMachines の SoftwareUpdate カテゴリ。
影響未パッチの VM は既知の脆弱性を通じた初期侵害・横移動の経路となりやすい。環境内の VM が集中してこの状態にある場合、単一インシデントが広範に波及するリスクがある。
推奨対応各 VM の更新状況を確認し、未適用のパッチを優先的に適用する。Azure Update Manager や自動更新ポリシーの導入可否を検討する。
優先度：高 Defender 不健全推奨事項の大量未対応（223 件 / Unhealthy）
観察事実Defender 推奨事項 407 件中 223 件（約 55%）が Unhealthy。高・中重大度合計で 192 件が未解消。
影響推奨事項の未解消は Secure Score の低下と、セキュリティリスクの見落としにつながる。特に "Unknown" カテゴリ 71 件は優先度が不明確なまま放置されるリスクがある。
推奨対応Azure Portal で Defender 推奨事項を重大度・カテゴリ別に確認し、High から順に是正または免除処理を実施する。"Unknown" カテゴリも個別精査を行う。
優先度：高 Owner 割り当てとサブスクリプションスコープ RBAC の過剰付与リスク
観察事実Owner 割り当て 13 件、サブスクリプションスコープ 29 件・管理グループスコープ 13 件。サービスプリンシパル 38 件が広範なスコープを保有。
影響Owner 権限の過剰付与は、アカウント・SP の侵害時に環境全体の制御を失うリスクをもたらす。最小権限の未徹底は監査指摘や規制リスクにもなりうる。
推奨対応各 Owner 割り当ての業務上の必要性を確認し、不要なものは削除・降格する。サービスプリンシパルのスコープと使用目的を棚卸しし、最小権限への移行を検討する。
優先度：中 ディスク・VM の可用性リスク（Advisor High / HighAvailability & OperationalExcellence）
観察事実Advisor 高影響度 43 件のうち、ディスク HighAvailability 11 件、VM OperationalExcellence 11 件。
影響可用性ゾーン未設定・バックアップ未構成などが示唆され、障害時のサービス停止や RTO/RPO 未達のリスクがある。
推奨対応Advisor の HighAvailability・OperationalExcellence High 推奨事項を個別確認し、可用性ゾーン設定・バックアップポリシーの適用状況を見直す。
優先度：中 Advisor Security 高影響度推奨事項（11 件 / VM）
観察事実Advisor Security カテゴリ合計 71 件のうち High が 11 件（Microsoft.Compute/virtualMachines）。
影響Advisor の Security 推奨事項は診断設定・暗号化・アクセス制御などを含む。Defender High と重複する場合もあるが、Advisor 固有の指摘が見落とされる恐れがある。
推奨対応Advisor Security High 推奨事項を Defender の対応リストと照合し、重複を整理したうえで未対応分を是正する。
